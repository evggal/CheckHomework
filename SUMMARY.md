## 💡 Как это работает

### Фронтэнд → Бекенд → Результат

```
1. Пользователь выбирает картинку (из 18)
   ↓
2. Нажимает "Отправить на обработку"
   ↓
3. Frontend отправляет WebSocket сообщение:
   { "image_name": "matrix_1.jpg" }
   ↓
4. Backend получает, проверяет БД, имитирует обработку
   ├─ Loading model (1 сек) → 15%
   ├─ Preprocessing (1.2 сек) → 35%
   ├─ OCR Recognition (1.5 сек) → 60%
   ├─ Solution Analysis (0.8 сек) → 85%
   └─ Finalizing (0.5 сек) → 100%
   ↓
5. Отправляет результат:
   {
     "status": "completed",
     "text_recognized": true,
     "solution_correct": true,
     "solution_content": "...решение в ASCII графике..."
   }
   ↓
6. Frontend показывает результаты и решение
```
